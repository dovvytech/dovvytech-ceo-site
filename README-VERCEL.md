# DOVVYTECH — site CEO / identité numérique

## 1. Avant le déploiement

Remplacer partout :

`https://YOUR-PROJECT.vercel.app`

par l'URL Vercel réelle du projet.

Fichiers concernés :
- index.html
- ceo.html
- robots.txt
- sitemap.xml

## 2. Déploiement Vercel

1. Créer un dépôt GitHub et y envoyer ces fichiers.
2. Dans Vercel, importer le dépôt.
3. Pour ce site statique, aucun build command n'est nécessaire.
4. Déployer.
5. Copier l'URL `*.vercel.app`.
6. Remplacer l'URL temporaire dans les fichiers puis redéployer.

## 3. Google Search Console

Après déploiement :
- ajouter la propriété du site dans Google Search Console ;
- inspecter `/ceo.html` ;
- demander l'indexation ;
- envoyer `/sitemap.xml`.

Google peut mettre plusieurs jours à explorer et réindexer les pages. L'indexation et l'affichage dans les résultats ne sont jamais garantis.

Ajouter progressivement des pages d'articles et de projets réellement publiés et signés par SAAH ALAIN.
